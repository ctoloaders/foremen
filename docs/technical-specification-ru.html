⚙️ 1. Технологический стек

Java 25 Spring Boot 6 Spring Security Spring Data JPA PostgreSQL 16 Flyway React 19 TypeScript 5 Vite TanStack Query Zustand Tailwind CSS i18next Docker Nginx

Архитектура

  • Backend — монолитный REST API (Java 25 + Spring Boot 6), Stateless (JWT), модульная структура пакетов
  • Frontend — SPA (React 19 + TypeScript), взаимодействие с бэкендом через REST/JSON
  • База данных — PostgreSQL 16, миграции через Flyway
  • Хостинг — VPS / cloud (Docker Compose: backend + frontend + DB + Nginx reverse proxy)
  • Будущее расширение — мобильное приложение (React Native / Capacitor), использующее тот же API

📦 2. Модули системы

Система состоит из 10 функциональных модулей. Каждый модуль — отдельный пакет в бэкенде и отдельная секция в панели фронтенда.

# Модуль Описание Ключевые сущности
1 Auth & Users Регистрация (OTP email), авторизация (JWT), управление пользователями, роли и разрешения User, Role, Permission, OtpToken
2 Проекты CRUD проектов ремонта, назначение клиента/менеджера/работников, метаданные Project, ProjectMember
3 Помещения Управление помещениями с размерами, авто-расчёт производных полей Room, RoomDimensions
4 Каталог работ Справочник ~230 позиций работ в 13 категориях, многоуровневые цены, двуязычные названия WorkCategory, WorkItem, PriceTier
5 Смета (Kosztorys) Создание сметы: выбор позиций × количество × цена, подытоги, утверждение, версионирование, изменения Estimate, EstimateItem, EstimateVersion, ChangeOrder
6 Склад (Magazyn) Регистрация закупок строительных/отделочных материалов, калькуляция НДС, суммы по проекту MaterialPurchase, MaterialCategory
7 Финансы Расчёт по проекту: стоимость контракта, изменения, материалы, фактуры, сальдо FinancialSummary, Invoice
8 Доставки График доставок: позиции по помещениям, статусы, история изменений DeliveryItem, DeliveryStatusHistory
9 Наряд-заказы (Zlecenia) Генерация наряд-заказов для бригад, расчёт выполненных работ WorkOrder, WorkOrderItem, WorkerSettlement
10 Gantt / График работ Диаграмма Ганта: категории работ vs недели, статусы фаз, вид только для чтения у клиента GanttPhase
Пакетные предложения (Budget/Norm/Lux) — подмодуль сметы. Генерирует предварительно заполненную смету на основе шаблона пакета и размеров помещений.

🏗️ 5. Архитектура

5.1 Структура пакетов бэкенда

pl.foremen.app/
├── auth/           # JWT, OTP, Spring Security config
├── user/           # User CRUD, roles, permissions
├── project/        # Project entity, assignments
├── room/           # Room dimensions, auto-calculations
├── catalog/        # WorkCategory, WorkItem, PriceTier
├── estimate/       # Estimate, items, versions, change orders
├── warehouse/      # MaterialPurchase (construction + finishing)
├── finance/        # FinancialSummary, Invoice
├── delivery/       # DeliveryItem, status history
├── workorder/      # WorkOrder, WorkOrderItem, settlement
├── gantt/          # GanttPhase (schedule)
├── reference/      # Все справочники (generic CRUD)
├── i18n/           # Поддержка локализации
└── common/         # Базовые сущности, исключения, DTO, утилиты

5.2 Ключевые технические решения

  • Аутентификация — JWT (access token 30 мин + refresh token 7 дней). OTP для клиентов — 6-значный код, TTL 15 мин, отправка через SMTP.
  • Авторизация — RBAC на уровне Spring Security + custom PermissionEvaluator для проверки модульного доступа.
  • Версионирование API — /api/v1/* prefix. Документация: OpenAPI 3.1 + Swagger UI.
  • Валидация — Bean Validation (Jakarta) + кастомные валидаторы для бизнес-правил.
  • Аудит — Spring Data Envers для версионирования смет; event log для активности.
  • Email — Spring Mail + шаблоны Thymeleaf для OTP и уведомлений.
  • Экспорт — Apache POI (Excel) + OpenPDF (PDF) для выгрузки наряд-заказов, смет.

5.3 Архитектура фронтенда

  • Роутинг — React Router v7, layout-based routes с guard'ами для ролей.
  • Управление состоянием — Zustand (глобальный: user, выбор проекта), TanStack Query (серверное состояние).
  • i18n — i18next + react-i18next, JSON-файлы для PL/RU/EN, dynamic import для ленивой загрузки.
  • UI Kit — Tailwind CSS + собственная дизайн-система (dark theme, зелёный акцент), компоненты: DataTable, StatusBadge, SummaryCard, Modal, FilterBar.
  • Формы — React Hook Form + Zod для валидации.
  • Gantt chart — кастомный SVG-компонент (без тяжёлых библиотек).

7.3 Milestone'ы

  • M1 (конец нед. 2) — Логин работает, проекты создаются, базовая навигация, деплой на dev-среду
  • M2 (конец нед. 6) — Полный цикл: создание проекта → добавление помещений → генерация сметы. Демо клиенту.
  • M3 (конец нед. 10) — Все модули работают. Полнофункциональная система на staging.
  • M4 (конец нед. 13) — i18n, экспорт, портал клиента. Feature freeze.
  • M5 (конец нед. 15) — Production deploy. Передача проекта.

🛡️ 8. Требования к качеству

Параметр Требование
Время отклика API: < 200ms (p95). Перерасчёт сметы при изменении размеров: < 2 сек.
Доступность 99.5% uptime (допустимо ~3.5 часа простоя в месяц для обслуживания)
