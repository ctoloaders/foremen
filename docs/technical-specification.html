⚙️ 1. Stos technologiczny

Java 25 Spring Boot 6 Spring Security Spring Data JPA PostgreSQL 16 Flyway React 19 TypeScript 5 Vite TanStack Query Zustand Tailwind CSS i18next Docker Nginx

Architektura

  • Backend — monolityczny REST API (Java 25 + Spring Boot 6), Stateless (JWT), modularna struktura pakietów
  • Frontend — SPA (React 19 + TypeScript), komunikacja z backendem przez REST/JSON
  • Baza danych — PostgreSQL 16, migracje przez Flyway
  • Hosting — VPS / cloud (Docker Compose: backend + frontend + DB + Nginx reverse proxy)
  • Przyszłe rozszerzenie — mobilna aplikacja (React Native / Capacitor) korzystająca z tego samego API

📦 2. Moduły systemu

System składa się z 10 modułów funkcjonalnych. Każdy moduł to osobny pakiet w backendzie i osobna sekcja w panelu frontendowym.

# Moduł Opis Kluczowe encje
1 Auth & Users Rejestracja (OTP email), logowanie (JWT), zarządzanie użytkownikami, role i uprawnienia User, Role, Permission, OtpToken
2 Projekty CRUD projektów remontowych, przypisanie klienta/kierownika/pracowników, metadane Project, ProjectMember
3 Pomieszczenia Zarządzanie pomieszczeniami z wymiarami, auto-kalkulacja pól pochodnych Room, RoomDimensions
4 Katalog prac Słownik ~230 pozycji prac w 13 kategoriach, ceny wielopoziomowe, dwujęzyczne nazwy WorkCategory, WorkItem, PriceTier
5 Kosztorys Tworzenie smety: wybór pozycji × ilość × cena, podsumy, zatwierdzanie, wersjonowanie, zmiany Estimate, EstimateItem, EstimateVersion, ChangeOrder
6 Magazyn Rejestracja zakupów mat. budowlanych/wykończeniowych, kalkulacja VAT, sumy per projekt MaterialPurchase, MaterialCategory
7 Finanse Rozliczenie projektu: wartość umowy, zmiany, materiały, faktury, salda FinancialSummary, Invoice
8 Dostawy Harmonogram dostaw: pozycje per pomieszczenie, statusy, historia zmian DeliveryItem, DeliveryStatusHistory
9 Zlecenia Generowanie naryad-zakazów (work orders) dla brygad, rozliczanie wykonanych prac WorkOrder, WorkOrderItem, WorkerSettlement
10 Gantt / Harmonogram Diagram Gantta: kategorie prac vs tygodnie, statusy faz, widok tylko-do-odczytu dla klienta GanttPhase
Pakietne oferty (Budget/Norm/Lux) — podmoduł kosztorysu. Generuje wstępnie wypełnioną smetę na podstawie szablonu pakietu i wymiarów pomieszczeń.

🏗️ 5. Architektura backendu

5.1 Struktura pakietów

pl.foremen.app/
├── auth/           # JWT, OTP, Spring Security config
├── user/           # User CRUD, roles, permissions
├── project/        # Project entity, assignments
├── room/           # Room dimensions, auto-calculations
├── catalog/        # WorkCategory, WorkItem, PriceTier
├── estimate/       # Estimate, items, versions, change orders
├── warehouse/      # MaterialPurchase (construction + finishing)
├── finance/        # FinancialSummary, Invoice
├── delivery/       # DeliveryItem, status history
├── workorder/      # WorkOrder, WorkOrderItem, settlement
├── gantt/          # GanttPhase (schedule)
├── reference/      # Все słowniki (generic CRUD)
├── i18n/           # Localization support
└── common/         # Base entities, exceptions, DTOs, utils

5.2 Ключевые решения

  • Аутентификация — JWT (access token 30 min + refresh token 7 дней). OTP для клиентов — 6-значный код, 15 мин TTL, отправка через SMTP.
  • Авторизация — RBAC на уровне Spring Security + custom PermissionEvaluator для проверки модульного доступа.
  • API versioning — /api/v1/* prefix. Документация: OpenAPI 3.1 + Swagger UI.
  • Валидация — Bean Validation (Jakarta) + custom validators для бизнес-правил.
  • Аудит — Spring Data Envers для версионирования кошторысов; event log для активности.
  • Email — Spring Mail + шаблоны Thymeleaf для OTP и нотификаций.
  • Export — Apache POI (Excel) + OpenPDF (PDF) для выгрузки zleceniе, кошторысов.

5.3 Архитектура фронтенда

  • Роутинг — React Router v7, layout-based routes с guard'ами для ролей.
  • State management — Zustand (глобальный: user, project selection), TanStack Query (серверное состояние).
  • i18n — i18next + react-i18next, JSON-файлы для PL/RU/EN, dynamic import для ленивой загрузки.
  • UI Kit — Tailwind CSS + собственная дизайн-система (dark theme, green accent), компоненты: DataTable, StatusBadge, SummaryCard, Modal, FilterBar.
  • Формы — React Hook Form + Zod для валидации.
  • Gantt chart — кастомный SVG-компонент (без тяжёлых библиотек).

7.3 Milestone'ы

  • M1 (конец нед. 2) — Login работает, проекты создаются, базовая навигация, deploy на dev-среду
  • M2 (конец нед. 6) — Полный цикл: создание проекта → добавление помещений → генерация коshtorysu. Демо клиенту.
  • M3 (конец нед. 10) — Все модули работают. Полнофункциональная система на staging.
  • M4 (конец нед. 13) — i18n, экспорт, portal klienta. Feature freeze.
  • M5 (конец нед. 15) — Production deploy. Handover.

🛡️ 8. Требования к качеству

Параметр Требование
Время отклика API: < 200ms (p95). Перерасчёт коstorysu при изменении размеров: < 2 сек.
Доступность 99.5% uptime (допустимо ~3.5 часа простоя в месяц для maintenance)
Безопасность HTTPS everywhere, JWT с ротацией, bcrypt для паролей, rate limiting, CORS, SQL injection protection (JPA parameterized)
Резервное копирование Ежедневный бэкап PostgreSQL, retention 30 дней
Масштабируемость До 50 одновременных пользователей, до 100 проектов. Монолит достаточен для этого масштаба.
Браузеры Chrome 120+, Firefox 120+, Safari 17+, Edge 120+
Мобильная адаптивность Responsive layout (tablet 768px+). Полноценное мобильное приложение — следующий этап.
