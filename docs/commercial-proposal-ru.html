🎯 1. Проблемы, которые решаем

На основе встречи с Алексеем (июль 2026) выявлены ключевые боли в текущих процессах компании:

🔴 Критические (P1)

  • Составление смет вручную — ~2.5 часа на одну смету. Снятие метражей по плану, умножение на расценки из справочника. Хотят: загрузил PDF → получил готовую смету.
  • Разноска банковских транзакций — 4–5 часов/день (~25 транзакций). Ручной перенос из выписки в Finmap по категориям/проектам.
  • Дублирование данных между системами — одни данные вносятся в Finmap + Битрикс + Excel. Расхождения, ошибки, потеря времени.

🟡 Важные (P2)

  • Длинная цепочка закупок — 7+ итераций согласования между клиентом, менеджером, закупщиком. Много ручной переписки.
  • Поиск материалов у поставщиков — ручная рассылка запросов, сбор ответов, сравнение цен.
  • Уведомления о доставках — ~20 доставок одновременно, бригадир не знает когда ждать. Данные уже есть в Битрикс, но нет нотификации.

🟢 Желательные (P3)

  • Планирование (Гант с зависимостями) — предупреждение: «плитку надо заказать за X дней до начала работ».
  • Клиентский портал — ссылка на проект вместо двух Excel-файлов. Апрув сметы прямо в системе.
  • Учёт допработ и аннексы — автоматическое создание аннекса к договору при изменениях.

💡 2. Предлагаемое решение

Единая платформа Foremen — веб-приложение с AI-агентом, которое становится единственным источником данных для всех процессов компании.

Ключевые принципы

  • Одна БД — единый источник правды — никакого дублирования между системами
  • Ролевой доступ — директор / менеджер / финансист / закупщик / прораб / клиент — каждый видит только своё
  • AI-агент для смет — загрузка PDF плана → распознавание помещений и размеров → генерация сметы по справочнику расценок
  • Клиентский портал — заказчик видит свой проект по ссылке, может согласовать смету или допработы
  • Интеграции — Finmap (синхронизация финансов), банковский API (транзакции), Битрикс24 (доставки, уведомления)

📋 8. Условия

  • Ставка: 45 €/час нетто
  • Оплата: помесячно по факту отработанных часов (timesheet)
  • Отчётность: еженедельный отчёт о прогрессе + доступ к задачам в трекере
  • Демо: каждые 2 недели — показ промежуточных результатов
  • Исходный код: передаётся клиенту по завершении каждого релиза
  • Гарантия: 30 дней бесплатного bugfix после каждого релиза
  • Хостинг: клиент оплачивает отдельно (~30–50 €/мес за VPS)
  • AI-сервисы: OpenAI API оплачивается клиентом по потреблению (~50–100 €/мес при активном использовании)
