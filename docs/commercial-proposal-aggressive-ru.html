⚡ 1. Концепция Accelerated

Вместо последовательных релизов P1 → P2, мы объединяем критические боли (P1) и операционные процессы (P2) в единый релиз в рамках бюджета EBRR (~15 000 €).

Как это возможно? Оптимизация за счёт: (1) упрощённый UI — функциональность без лишнего полиша, (2) AI-assisted development — ускорение кодогенерации, (3) MVP-подход к каждому модулю — минимальная рабочая версия, доработка после обратной связи, (4) общие компоненты переиспользуются между модулями, (5) поиск поставщиков (AI) перенесён в P3.

Что входит в P1 (Accelerated)

  • ✅ AI-генерация смет по PDF
  • ✅ Ручное составление сметы
  • ✅ Финансы + импорт транзакций
  • ✅ Склад и учёт материалов
  • ✅ Workflow закупок (упрощённый)
  • ✅ Доставки + SMS-уведомления бригадиру
  • ✅ Ролевой доступ (все 6 ролей)

Упрощения (Tradeoffs)

  • ⚠️ UI функциональный, но без анимаций и расширенных фильтров — доработка в P2
  • ⚠️ Интеграция Finmap: импорт CSV-выписок вместо полного API (API — в P2)
  • ⚠️ Workflow закупок: 3 статуса (Заявка → Согласована → Закуплено), без сложной маршрутизации
  • ⚠️ Уведомления: только SMS через простой gateway, без push
  • ⚠️ AI-поиск поставщиков перенесён в P3

📋 5. Условия

  • Ставка: 45 €/час нетто
  • Оплата: помесячно по факту отработанных часов (timesheet)
  • Отчётность: еженедельный отчёт + доступ к трекеру задач
  • Демо: каждые 2 недели — показ промежуточных результатов
  • Исходный код: передаётся клиенту по завершении каждого релиза
  • Гарантия: 30 дней бесплатного bugfix после релиза
  • Хостинг: ~30–50 €/мес (клиент)
  • AI-сервисы: OpenAI API ~50–100 €/мес (клиент)

➡️ 6. Следующие шаги

  • 1. Выбор плана (Стандартный или Accelerated) и подписание договора
  • 2. Получение от клиента: прайс-лист, 2–3 PDF-плана, шаблон сметы, доступ к банковской выписке (CSV)
  • 3. Старт — неделя 1: инфра + авторизация + каталог работ
  • 4. Демо через 4 недели: генерация сметы по PDF + базовый финансовый модуль
  • 5. Демо через 8 недель: закупки + доставки + SMS
  • 6. Релиз P1 — неделя 10–12
