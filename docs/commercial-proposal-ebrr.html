1. Ключевые возможности платформы

  • Прейскурант работ для клиента — каталог работ с ценами для клиента + возможность индивидуальных скидок под проект
  • Внутренний прейскурант себестоимости — справочник себестоимости работ (для расчёта маржи и нарядов работникам)
  • Менеджмент помещений — управление помещениями с размерами, авто-расчёт площадей, привязка к проекту
  • Менеджмент проектов — создание и ведение проектов, назначение команды, метаданные
  • Клиентский портал — смета, оферта, согласование допработ, график работ и доставок, контроль оплат, перечень строительных и отделочных материалов
  • Создание сметы/оферты — ручной режим + AI-агент (загрузка PDF плана → авто-генерация сметы по каталогу)
  • Портал прораба — профили работников, графики работ на проекте, отчётность по выполнению, расчёты с работниками (помесячные ведомости с группировкой факта и оплат), внесение первичной фин. документации (фактуры, чеки), перечень строительных и отделочных материалов
  • Портал работника — read-only доступ к своим объектам, внесение факта выполненных работ, read-only доступ к зарплатной ведомости
  • Портал менеджера — фин. документы, доступ к проектам, коммуникация через клиентский портал, контроль закупок, поиск поставщиков (ручной + AI-агент)
  • Поддержка 2 языков — PL/RU (с возможностью добавления EN)
  • Настраиваемая модель доступа — суперадмин создаёт роли с уровнями доступа (read/edit/admin) к разным модулям (клиентский портал, закупки, прейскуранты, списки работников, проекты, помещения и т.д.)

4. Модель доступа

Суперадмин создаёт роли с гранулярным доступом. Для каждого модуля (клиентский портал, закупки, прейскуранты, списки работников, проекты, помещения, финансы, доставки) устанавливается уровень: нет доступа / только чтение / редактирование / полный (админ). Предустановленные роли: Заказчик, Работник, Прораб, Менеджер, Суперадмин.

5. Условия

  • Ставка: 45 €/час нетто
  • Оплата: помесячно по факту отработанных часов (timesheet)
  • Отчётность: еженедельный отчёт + доступ к трекеру задач
  • Демо: каждые 2 недели — показ промежуточных результатов
  • Исходный код: передаётся клиенту
  • Гарантия: 30 дней бесплатного bugfix после релиза
  • Хостинг: ~30–50 €/мес (клиент)
  • AI-сервисы: OpenAI API ~50–100 €/мес (клиент)

6. Следующие шаги

  • 1. Согласование скоупа и подписание договора
  • 2. Получение от клиента: прайс-лист, PDF-планы, шаблон сметы, доступ к банковской выписке
  • 3. Старт — неделя 1: инфра + авторизация + модель доступа
  • 4. Демо через 4 недели: генерация сметы + портал менеджера
  • 5. Демо через 8 недель: портал прораба + клиентский портал
  • 6. Релиз — неделя 16–18
