# Foremen — демо-презентация для заказчика

Презентация готового функционала платформы (стадия проектирования проекта).
Все скриншоты сняты с живой системы, польская локаль (PL), описания — на русском.

## Файлы

| Файл | Описание |
|------|----------|
| `foremen-demo.pptx` | Презентация PowerPoint (47 слайдов, 16:9, со встроенными скриншотами). |
| `foremen-demo.html` | Та же презентация в виде самодостаточного HTML (листается стрелками ← / →, `F` — полный экран). |
| `screens/` | Исходные скриншоты (1440×900, PNG). |
| `slides.py` | Единый источник правды: тексты слайдов и порядок. |
| `build_pptx.py` / `build_html.py` | Генераторы PPTX / HTML из `slides.py`. |

> HTML открывается двойным кликом в браузере. Если браузер блокирует загрузку
> картинок с `file://`, запустите локальный сервер в этой папке:
> `python3 -m http.server 8099` и откройте `http://localhost:8099/foremen-demo.html`.

## Структура (47 слайдов)

1. **Обложка**
2. **Глава 1 — Администратор и системные функции:** вход, панель, пользователи,
   роли, матрица доступа (ABAC), аудит, типы документов, шаблоны документов.
3. **Глава 2 — Справочники и каталоги:** единицы, VAT, типы рабочих, категории работ,
   каталог работ, цены, нормы расхода, отделочные материалы, пакеты офер, ассортимент (zł/m²).
4. **Глава 3 — Менеджер и пространство проекта:** вход, список проектов, обзор + трекер
   готовности, затем по порядку вкладки: Помещения → Смета → Материалы → Маржа → Оферта →
   Команда → Планировочный Гант → Подписание документов (+ карточка документа).
5. **Глава 4 — Клиент:** вход, проекты клиента, обзор, приёмка оферты, выбор отделочных
   материалов, замена материала, запрос скидки/узгоднение, документы и подпись, уведомления.
6. **Итог.**
