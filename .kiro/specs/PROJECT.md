# Foremen — Система управления ремонтами

## Обзор проекта

Foremen — полнофункциональная платформа для управления ремонтными проектами. Включает планирование, ведение смет, управление закупками, распределение задач, контроль хода работ и клиентский портал.

## Стек технологий

### Backend
- **Язык:** Java 25
- **Фреймворк:** Spring Boot 4
- **Сборка:** Gradle
- **ORM:** Spring Data JPA + custom DAO views
- **Маппинг:** MapStruct
- **Авторизация:** Role-based access control (RBAC) + project-level roles
- **i18n:** Поддержка интернационализации в интерфейсе и в базе данных
- **Основа:** Кастомный CRUD-фреймворк из проекта tickets (access/common/config/controller/dao/service/utils)

### Frontend
- **Фреймворк:** React
- **Дизайн:** iOS-like, mobile-first
- **Адаптивность:** Mobile-first подход

### Инфраструктура
- **Облако:** Google Cloud
- **БД:** PostgreSQL
- **Деплой:** Cloud Run / GKE

## Роли в системе

| Роль | Описание |
|------|----------|
| Администратор | Полный доступ ко всем сущностям и операциям |
| Менеджер | Управление проектами, сметами, закупками |
| Прораб | Управление работами на объекте, распределение задач |
| Работник | Выполнение задач, отчетность |
| Сметчик | Работа со сметами и прейскурантами |
| Клиент | Просмотр хода работ, согласование |

## Роли на проекте

Помимо системной роли, у каждого пользователя может быть роль на конкретном проекте. Доступ к данным проекта определяется комбинацией системной роли и роли на проекте.

## Рендеринг интерфейса по роли

Отдельных «рабочих пространств» под каждую роль нет. Роль пользователя вместе с матрицей пермишенов (ABAC) — единственный источник правды о том, какие разделы, действия и данные доступны и рендерятся. Интерфейс адаптируется автоматически через видимость меню и действий (FOR-03-07). Дополнительно название текущей роли отображается в топбаре (справа вверху, слева от переключателя языка) для явности.

## Спецификации (очередность разработки)

### Готовые

| # | Код | Название | Описание |
|---|-----|----------|----------|
| 1 | FOR-01 | Структура бекенда | Кастомный CRUD-фреймворк, базовая архитектура |
| 2 | FOR-02 | Админ-панель | Настройка ролей доступа, полный доступ ко всем сущностям |
| 3 | FOR-03 | Система авторизации | Логин, получение ролей, видимость меню, валидация доступов |

### Новые

| # | Код | Название | Описание |
|---|-----|----------|----------|
| 4 | FOR-04 | Базовые сущности | Проекты, помещения, единицы измерения, валюты, ставки VAT, прейскурант работ (вид работы с ценой, датой активности цены, привязкой к валюте и единице измерения, i18n-названием) + сид значений из существующего Excel-прейскуранта |
| 5 | FOR-05 | Смета проекта (kosztorys) | Создание сметы проекта на базе прейскуранта и базовых сущностей |
| 6 | FOR-06 | План-график работ | Набор прораба, команды работников, диаграмма Ганта, календари по проекту |
| 7 | FOR-07 | Трекинг закупок и работ | Учёт закупок и выполненных работ по проекту |
| 8 | FOR-08 | AI-ассистент сметы | AI-assisted создание сметы: оркестратор + tools + user session + персистентность чата per project |
| 9 | FOR-09 | Клиентский портал | Read-only смета / графики / списки закупок + коммуникация: согласование сметы, скидки, пакеты услуг, спец-цены на проект, коммуникация по закупкам (запрос клиента → аппрув менеджера/прораба, согласование цен, выбор вариантов закупки) |
| 10 | FOR-10 | Финансовый учёт | Загрузка первичной документации по закупкам, импорт банковских проводок, разнесение проводок по проектам и статьям затрат |
| 11 | FOR-11 | Расчёт зарплат | Расчёт зарплат работников |
| 12 | FOR-12 | Инфраструктура | Деплой в Google Cloud (добавляется по мере готовности проекта) |

> **Убрано из роадмапа:**
> - Прежний FOR-04 (i18n) — уже реализовано и гарантируется хуками, отдельная спека не нужна.
> - Прежние рабочие пространства по ролям (manager/foreman/worker workspaces) — не нужны: роль пользователя + пермишены уже являются источником правды для того, какой интерфейс рендерить. Вместо отдельных панелей достаточно явно показывать название текущей роли в топбаре (справа вверху, слева от переключателя языка).
