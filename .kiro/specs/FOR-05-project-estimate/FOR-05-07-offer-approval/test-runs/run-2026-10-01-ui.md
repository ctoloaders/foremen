## Исправленный баг (контекст прогона)

До пересборки фронта вкладка «Оферта / согласование» зависала на спиннере «Загрузка оферты…», хотя API отдавал 200. Причина — рассинхрон контракта: бэкенд для исполнителя отдаёт обёрнутую форму { offer, control }, а фронтовые типы/OfferTab читали плоскую модель (offerId на верхнем уровне → undefined). Исправлено нормализацией wrapped→flat в API-слое фронта (+ переименование perLineOfferPrice/perCategoryOfferPrice, удаление approvedRevision). После пересборки образа фронта вкладка отрисовывается полностью.
